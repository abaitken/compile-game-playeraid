# Card: Unity 1

## Card Text

### Top

```
**Start:** If this card is covered, you may shift this card.
```

### Middle

```
If there are 5 or more Unity cards in the field, flip the Unity protocol to the compiled side and delete all cards in that line.
```

### Bottom

```
Unity cards may be played face-up in this line.
```

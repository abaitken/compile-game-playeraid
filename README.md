# Compile Player Aid

A site aimed at providing aid to players of the card game Compile (Compile: Main 1 etc).

Features card list, protocol lists, tools to allow players to randomly pick protocols and FAQ from the codex as well as custom written FAQ.

## Dependencies

- knockoutJS: for simple view binding
- marked: Markdown rendering (and custom extensions)
- materialdesignicons: For Icons

## Usage

Just open index.html in your browser.

Or, for partially supported Markdown you can use [FAQ Index](src/topics/index.md) or [Complete all in one](src/topics/complete.md) topic.
